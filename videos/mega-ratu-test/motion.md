# Mega Ratu test — motion plan

A 15-second sample for Mega Ratu that moves exactly like the reference video
(`videos/reference-motion/TRANSITIONS.md`, transitions T1–T17), dressed in the Mega Ratu fonts and colours from
`design.md`. The JRM Holistik logo appears only in the last 3 seconds.

## Format

| | |
|---|---|

| Frame | 1080 × 1920, vertical (TikTok, Reels, Shorts) |
| Sound | None in this test; add a sound in the app when posting |

## Rules kept from the reference

1. Each state grows out of the one before: bottle → card → list → card → bottle, then the logo. No cuts, no fades.
2. Arrivals spring (overshoot, then settle); exits speed up and shrink into whatever takes them.
3. Hitting something causes a reaction: stretch and recoil at the card's ends, a pop and tilt as each card lands.
4. Moves overlap; the gaps shrink at the climax (0.40 → 0.33 → 0.27 s).
5. The middle runs backwards (T15 mirrors T4, T16 mirrors T3), and the logo's entrance repeats the bottle's.
6. Fast moves of 0.2–0.35 s, then still holds of 0.5–1 s.

## Changes from the reference, and why

- **Logo moved to the end.** As asked, the reference's opening "logo" role is played by the bottle, and the
  JRM Holistik logo only appears at 12.0–15.0 s, entering with the same drop and bounce (T1–T2).
- **Bottle hold before the logo.** 10.27–11.40 s holds the bottle so the product registers before the logo replaces it.
- **Logo holds to the end**, instead of shrinking out and looping, so it is readable for 2.4 s.
- **Stack centred at x 450**, not the frame's middle, so nothing goes under TikTok's buttons on the right.
- **Bottle turns once, not 1½ times**, so it ends face-on with its label readable.
- **Each card arrival flashes a brand colour**, instead of the reference's bright red, amber, green and magenta.
